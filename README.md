# FAQ Chatbot — Rule-Based to Machine Learning Upgrade

## Overview

This project upgrades a rule-based FAQ chatbot into a machine learning-based chatbot using TF-IDF and cosine similarity.

The chatbot compares user questions with a knowledge base and returns the most relevant answer.

## Features

- FAQ knowledge base
- TF-IDF text representation
- Cosine similarity matching
- Confidence-based responses
- Comparison with a rule-based baseline
- Test cases and evaluation results

## Technologies

- Python
- Scikit-learn
- TF-IDF
- Cosine Similarity
- HTML
- CSS
